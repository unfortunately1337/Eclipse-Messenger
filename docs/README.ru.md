## Что такое Eclipse

Веб-мессенджер с личными чатами, группами и каналами. В одном интерфейсе собраны
переписка, медиа, музыка, инструменты сообществ и настройки профиля. Можно выбрать
обычное оформление или Liquid Glass; интерфейс адаптируется к компьютеру и телефону.

- Сообщения, ответы, пересылка и закрепления.
- Фото, видео, голосовые сообщения и видеокружки.
- Музыкальный плеер, мини-плеер и отправка музыки друзьям.
- Реакции с настройкой разрешённых вариантов, опросы и роли администраторов.
- Темы, фоны, анимированные баннеры и эмодзи-статусы.
- Вход по почте и QR, управление сессиями и двухфакторная аутентификация.
- Секретные чаты с отдельным жизненным циклом и таймером.
- Платформа ботов и JavaScript SDK.

Здесь опубликованы исходники приложения и сервера, миграции, тесты и SDK.
Публикация кода не является независимым аудитом безопасности. У режимов переписки
разные свойства шифрования и восстановления ключей: см. [SECURITY.md](../SECURITY.md).

**Иллюстрации:** бинарные файлы сторонних Telegram-паков и анимаций без
подтверждённого разрешения на распространение не включены. Для них работают
локальные замены через системные эмодзи. Исходники механизма эмодзи сохранены,
но графика отличается от production. Подробнее: [ARTWORK.md](ARTWORK.md).

## Локальный запуск

Нужны Node.js **22.13+**, npm и доступ к PostgreSQL, Redis и S3-совместимому
хранилищу. Сервисы можно установить самостоятельно или подключить у провайдера.

```sh
git clone https://github.com/unfortunately1337/Eclipse-Messenger.git
cd Eclipse-Messenger
npm ci
npm run setup:local
```

Команда `setup:local` создаёт локальный `.env`, генерирует независимые секреты
и не перезаписывает существующий файл. Замените примеры настроек подключения
на параметры собственных сервисов.

1. Создайте базу PostgreSQL и пользователя, укажите `DATABASE_URL`.
2. Подключите Redis через `REDIS_URL`.
3. Создайте приватный bucket в S3-совместимом хранилище и заполните `S3_*`.
4. Укажите рабочие SMTP-настройки: без доставки писем нельзя получить код.
5. Настройте собственные ключи Pusher Channels для обновлений в реальном времени.
   Pusher Beams нужен только для соответствующих push-уведомлений.

```sh
npm run db:migrate
npm run dev
```

Откройте **http://localhost:3000**. Данные пользователей, production-секреты и медиа
отсутствуют. Это полноценное приложение, которому нужны сервисы, а не автономная
демонстрация.

## Проверки и развёртывание

```sh
npm test
node --test sdk/eclipse-bot/index.test.mjs
npm run build
npm start
```

При `npm start` автоматически применяются миграции. Пять проверок бинарных ресурсов
пропускаются, если соответствующие необязательные оригиналы не установлены;
локальные замены проверяются отдельными тестами.

Для production используйте HTTPS, собственные секреты и ограниченный доступ к БД,
Redis и хранилищу. Не меняйте долговременные ключи шифрования без миграции данных.
Подробнее — в [основном README](../README.md#production) и
[инструкциях обслуживания](MAINTENANCE.md).
