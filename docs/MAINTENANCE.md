# Инструменты проекта

`scripts/` содержит воспроизводимые инструменты приложения. Они не являются временными сценариями монтажа или одноразовыми правками исходников.

| Файл | Назначение |
| --- | --- |
| `check-node-version.cjs` | Проверка поддерживаемого Node перед запуском, тестами и сборкой. |
| `patch-braces.cjs` | Защитная правка установленной зависимости; вызывается из `postinstall`. |
| `generate-icon-subsets.cjs` и `.d.cts` | Генерация используемых SVG-иконок и типы для конфигурации Next.js. |
| `build-emoji-picker.cjs` | Подготовка анимированных превью стандартных реакций. |
| `measure-reaction-icons.cjs` | Измерение видимой области реакций для выравнивания размера анимаций. |
| `build-inline-emoji.cjs` | Подготовка качественных стандартных эмодзи для текста и крупных сообщений. |
| `build-emoji-status-previews.cjs` | Подготовка актуальных анимированных и статичных превью пользовательских эмодзи из TGS. |
| `i18n-audit.cjs`, `i18n-inventory.cjs` | Проверка полноты перевода и сбор инвентаря строк. |
| `set-verification.mjs` | Административная выдача и отзыв галочки с доверенным доступом к БД. |
| `e2e-preflight-check.mjs` | Проверка состояния ключей перед обслуживанием. |
| `e2e-rewrap-db-secrets.mjs` | Перешифрование серверных секретов при ротации ключа. |
| `e2e-reconcile-shared-holders.mjs` | Согласование владельцев общих ключей. |
| `e2e-repair-identities.mjs` | Восстановление согласованности идентификаторов шифрования. |
| `media-backfill.js` | Заполнение метаданных ранее загруженных медиа. |
| `migrate-e2e-at-rest.js` | Миграция старых серверных зашифрованных данных. |

Перед инструментами, изменяющими БД, сделайте резервную копию и прочитайте их аргументы и режим проверки. Обычная установка и запуск не требуют выполнения старых исправляющих SQL вручную: схема разворачивается из `prisma/migrations`.

В открытой версии оригинальные сторонние ресурсы эмодзи не включены: вместо них работают локальные замены через системные шрифты. См. [ARTWORK.md](ARTWORK.md). Генераторы не запускаются при обычной сборке. Если у вас есть разрешение на использование исходных GIF/TGS, для генерации нужны `sharp` из дерева зависимостей, а для TGS ещё Chrome/Chromium (`CHROME_PATH`). Перед публикацией ресурсов проверьте права и сохраните их лицензию.

SDK для скачивания из `public/bot-api` нужен приложению отдельно от исходного SDK. При обновлении SDK синхронизируйте обе версии и запускайте `node --test sdk/eclipse-bot/index.test.mjs`.
