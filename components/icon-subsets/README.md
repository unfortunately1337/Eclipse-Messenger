These files contain the exact SVG functions used from the installed `react-icons` version. They are generated by `scripts/generate-icon-subsets.cjs` and resolved by both Turbopack and Webpack; normal source imports and TypeScript types remain unchanged.

Do not edit generated SVG data. After adding or changing a `react-icons` import while the development server is running, run:

```sh
node scripts/generate-icon-subsets.cjs
```

Generation also runs when Next loads its configuration. Source libraries and their licenses are listed in `LICENSE`.
